# Ora et Lege

A small, offline web app for learning Ecclesiastical (Church) Latin, 25 minutes a day:
prayers and the Mass Ordinary word by word (Spanish and English meanings), Church pronunciation
(spoken with an Italian voice), spaced review (FSRS-5) and short speaking/writing drills.

Open it on an iPhone in Safari, then Share › Add to Home Screen. Progress stays on the device;
use Progress › Save backup to move it.

Texts: traditional Latin prayers and liturgy (public domain); translations written for this app.
Built by Spark (Claude Code) for AMT.
